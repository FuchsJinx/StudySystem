# AGENTS.md — инструкции для ИИ-агентов

## Проект

MVP университетской социальной сети: рейтинги (АР), баллы активности (БУА/БОА), лента наград, опросы, админка, уведомления, аналитика, LLM-функция.

**Срок:** 22.10.2026 – 12.11.2026 · **Защита:** 19.11.2026

## Стек (зафиксирован)

| Слой | Выбор |
|------|--------|
| Backend | Java 21 · Spring Boot 3.4 · Maven |
| Frontend | React 18 · Vite · TypeScript |
| БД | PostgreSQL 16 · Flyway |
| Auth | JWT |
| Запуск | `docker compose up --build` |
| CI | GitHub Actions (`.github/workflows/ci.yml`) |

Корень: `backend/`, `frontend/`, `docker-compose.yml`. Spec БД: `docs/spec/18-database.md`. Сценарии: `docs/spec/19-user-flows.md`.

## Документы — источник правды

1. `docs/spec/` — требования и архитектура. **Менять правила рейтинга/баллов только через spec, потом код.**
2. `docs/qa/` — стратегия и кейсы тестирования.
3. `docs/agent-log.md` — журнал: задачи агенту, ошибки, исправления.
4. Этот файл — как запускать, тестировать, соглашения.

## Обязательный объём

Реализуем **все** модули 1–11 (база + опции). При конфликте сроков приоритет: **1 → 2 → 3 → 4 → 8 → 7 → 5 → 6 → 9 → 10 → 11**.

## Как работать агенту

1. Перед задачей прочитай релевантный файл из `docs/spec/` и DoD задачи в `08-tasks-breakdown.md`.
2. Пиши тесты **до или вместе** с кодом (TDD для домена рейтинга и бюджета).
3. Не выдумывай бизнес-правила: если в spec нет — спроси человека или зафиксируй вопрос в `agent-log.md`.
4. После сессии добавь запись в `docs/agent-log.md`.
5. Не коммить секреты (`.env` с паролями, API keys).

## Соглашения по коду

- Язык UI и сообщений API ошибок: **русский** (для демо вуза).
- Имена в коде: английский (`academicRating`, `activityPoints`).
- Миграции БД версионируются; seed обязателен при `docker compose up`.
- Настройки списания/бюджета — только через таблицу/файл Settings, не хардкод в сервисах.
- Фоновая джоба списания АР: интервал из Settings (для проверки — 1 минута).
