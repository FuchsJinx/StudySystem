# UniRate — подготовка к защите

Лимит выступления: **15 минут**. Площадка БГТУ, жюри M-Social.

## Структура доклада (обязательные пункты ТЗ)

1. Цель и задачи  
2. Роли в команде (PM / FE / BE / QA…)  
3. Архитектура и стек (схема)  
4. UI/UX: демо или скриншоты по W2–W6  
5. План тестирования (QA): сценарии + инструменты  
6. Работа с агентами: инструменты, делегирование, ошибки из `agent-log`, как ловили  
7. План интеграции в вуз  
8. Развитие продукта  

## Демо-скрипт (черновик ~8 мин)

1. Login student → профиль АР/БУА/БОА  
2. Просроченная задача → тик списания (показать AR↓) → сдача → accept  
3. Активность → award → лента наград  
4. Опрос / админ импорт / ИИ-черновик — по 30–40 сек  
5. `docker compose up` и тесты — один слайд
