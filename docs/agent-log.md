## 2026-11-10 — Автономный агент / DeepSeek Harness

**Задача:** Аудит репозитория, реализация модулей 1–11, тесты, Docker, Git-история.
**Промпт / скилл:** полное ТЗ пользователя + `AGENTS.md`, `docs/spec/`, `docs/qa/`.
**Результат:** этап 1 (auth, профили, подтверждение) и этап 2 (АР, списание) — реализованы; 34 backend + 13 frontend тестов зелёные, Playwright-сценарий создания задачи → сдачи → приёмки пройден.

**Ошибка агента:** миграция V3 падала на `ALTER TYPE` для `membership_status` — default-значение ссылалось на удаляемый enum-тип; для `award_feed_items.currency` CHECK-ограничение сравнивало varchar с enum.
**Как обнаружили:** запуск приложения + Flyway; прогон миграций в scratch-БД через psql.
**Исправление:** перед сменой типа сброшены DEFAULT, удалено CHECK-ограничение, после конвертации значения и ограничения восстановлены (VARCHAR + CHECK).

**Ошибка агента:** Vite watcher падал с EBUSY на временных каталогах `.tmpdir`, создаваемых инструментом записи файлов.
**Как обнаружили:** падение dev-сервера при сохранении страницы.
**Исправление:** `server.watch.ignored` для `**/.*.tmpdir/**`, `**/*.tmp`; перезапуск Vite.

**Ошибка агента:** интеграционный тест ожидал `debitedStudents == 0` после сдачи одного студента, но в группе оставался второй просроченный студент.
**Как обнаружили:** `mvn -Dtest=RatingIntegrationTest test`.
**Исправление:** проверка перенесена на АР конкретного студента, а не на глобальный счётчик тика.

**Что сработало:** интеграционные тесты на реальном PostgreSQL (`@SpringBootTest` + Flyway), прямой вызов тика списания, pessimistic lock на submission/student; Playwright с системным Edge (`channel: msedge`) без скачивания браузера.
