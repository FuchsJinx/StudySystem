# Acceptance checklist

Отмечать перед сдачей. База — блокер, если не 100%.

## Инфраструктура

- [ ] `docker compose up --build` поднимает проект одной командой
- [ ] Seed: справочники + demo users
- [ ] AGENTS.md / docs/spec / docs/qa / agent-log / скиллы в репо
- [ ] Тесты гоняются документированной командой

## Модуль 1 — Профиль

- [ ] Регистрация student/teacher по правилам
- [ ] Профиль виден auth-пользователям
- [ ] АР, БУА, БОА, история, задания

## Модуль 2 — АР

- [ ] Создание checkpoint, дедлайн, cost
- [ ] Старт 1000; семестр +N с cap
- [ ] Submit ссылка/файл
- [ ] Автосписание по settings
- [ ] Accept / Return (+ возобновление)
- [ ] Статусы: В процессе / Сдано / Просрочено / Принято

## Модуль 3 — Баллы

- [ ] Активности учебные/общественные
- [ ] Enroll для SOCIAL
- [ ] % участия → баллы
- [ ] Бюджет преподавателя по группе/месяцу
- [ ] История формата из ТЗ

## Модуль 4 — Лента наград

- [ ] Публичная лента, newest first, только auth

## Модуль 5 — Опросы

- [ ] Создание, SINGLE/MULTIPLE, анонимность, голос, статистика

## Модуль 6 — Персональная лента

- [ ] События student/teacher по spec 12

## Модуль 7 — Подтверждение

- [ ] Email verify
- [ ] Подтверждение группы teacher/lead; блок до confirm

## Модуль 8 — Админ

- [ ] Справочники, CSV/Excel, семестры, settings

## Модуль 9 — Уведомления

## Модуль 10 — Аналитика

- [ ] Динамика АР, рейтинги БУА/БОА, бюджет по месяцам
