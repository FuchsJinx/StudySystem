# 16 — Модуль 10: Аналитика для преподавателя

Доступ: Teacher по своим группам (с которыми работает) ⚠️ РЕШЕНИЕ: группы, куда создавал checkpoint/activity, или явная привязка teacher↔group.

## Виджеты

1. **Динамика АР по группе** — среднее / медианы по дням или история ledger AR.
2. **Рейтинг студентов** по БУА и по БОА (две таблицы или табы).
3. **Статистика начислений и расхода бюджета** по месяцам (bars).
