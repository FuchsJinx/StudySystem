# 07 — UI-сценарии и wireframe-макеты

Текстовые макеты экранов (mobile-first колонка ~360px + desktop). Не финальный дизайн — каркас для Frontend и QA.

---

## Навигация

**Student:** Лента наград · Мои задачи · Активности · Опросы · Моя лента · Профиль · Уведомления  

**Teacher:** Задачи · Активности · Опросы · Бюджет · Аналитика · Профиль · Уведомления  

**Admin:** Справочники · Импорт · Семестры · Настройки

## W11 — ИИ-помощник (модуль 11)

В форме создания задачи: блок «Сгенерировать описание» — тезисы → черновик в textarea.  
В опросе: «Сводка ответов».  
В профиле студента: «Как поднять рейтинг?» → 3–5 советов по данным профиля.

---

## Ключевые user journeys (для e2e)

1. Регистрация студента → verify email → подтверждение группы → видит задачу.  
2. Преподаватель создаёт checkpoint → студент просрочил → АР падает → сдал → приняли.  
3. SOCIAL активность → enroll → award 50% → лента наград + бюджет −N.  
4. Опрос → голос → статистика.  
5. Админ импорт CSV → новый студент в группе.
