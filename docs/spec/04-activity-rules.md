# 04 — Баллы активности (модуль 3)

Положительное подкрепление. БУА и БОА — **раздельные** валюты.

## Создание активности

Преподаватель задаёт:

- название, описание
- тип: `ACADEMIC` → БУА | `SOCIAL` → БОА
- целевые группы
- дата проведения
- maxPoints

Студенты видят активность и maxPoints заранее.

## Запись (только SOCIAL)

Студент записывается заранее. Баллы за общественную активность — **только записавшимся**.

Для ACADEMIC запись ⚠️ РЕШЕНИЕ: не требуется; преподаватель отмечает участников из целевых групп.

## Подтверждение участия

После мероприятия преподаватель отмечает участников и уровень: **25 / 50 / 75 / 100 %**.

```
awarded = floor(maxPoints * level / 100)
```

Запись в PointLedger + публикация в ленту наград (модуль 4).

Формат истории у студента:

`[Дата] - [+50 БОА] - «Помощь в организации конференции» от [ФИО преподавателя]`

## Бюджет преподавателя

- Лимит на **каждую группу** на **календарный месяц**: `teacherMonthlyBudgetPerGroup` (дефолт **1000**).
- Восстановление: новый месяц → остаток = лимит (не перенос ⚠️).
- Нельзя превысить: при начислении проверять сумму уже выданных баллов (БУА+БОА) этой группой в месяце.
- UI: остаток бюджета + статистика начислений преподавателя.

⚠️ РЕШЕНИЕ: бюджет считается по сумме **начисленных** баллов активности, не по maxPoints активностей.

## Запреты

- Начисление студенту без подтверждённой группы (модуль 7).
- Начисление не из целевой группы активности.
- SOCIAL без enrollment.
