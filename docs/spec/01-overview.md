# 01 — Обзор продукта

## Цель

Веб-приложение для взаимодействия студентов и преподавателей через систему рейтингов и достижений.

## Scope

| | Модули | Статус |
|---|--------|--------|
| База | 1 Профиль · 2 АР · 3 Баллы · 4 Лента наград | Обязательно, 100% |
| Опции | 5–11 | **Все реализуем** |

## Роли

| Роль | Регистрация | Возможности |
|------|-------------|-------------|
| Student | email + пароль; ФИО; факультет + группа (из справочника) | Профиль, свои АР/БУА/БОА, задания, активности, опросы, ленты |
| Teacher | email + пароль; ФИО; кафедра (из справочника) | Задания/активности/опросы, приём работ, начисление баллов, бюджет, аналитика |
| Admin | ⚠️ seed / отдельная регистрация | Справочники, CSV/Excel, семестры, Settings |
| GroupLead (староста) | флаг у Student | Подтверждение принадлежности к группе (модуль 7) |

## Нефункциональные требования

- `docker compose up` поднимает всё + seed.
- Unit: логика рейтинга и баллов; e2e: основные сценарии.
- UI на русском; адаптив — сильный плюс.
- Команда объясняет любой код на защите.

## Критерии оценки (ориентир)

База 25% · агентский процесс 25% · опции 20% · инженерия 10% · UI/UX 10% · презентация 10%.

## Вне scope / позже

- Мобильные нативные приложения.
- Интеграция с реальной АСУ вуза (только план на защите).
