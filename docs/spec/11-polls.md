# 11 — Модуль 5: Онлайн-голосования и опросы

## Создание

Преподаватель: title, description, endsAt, targetGroups[], isAnonymous, questions[].

### Вопрос

- text  
- type: `SINGLE` | `MULTIPLE`  
- options: string[] (≥2)

## Участие

- Голосуют студенты целевых групп с подтверждённой группой.
- Один ответ на опрос на студента (изменение ⚠️ РЕШЕНИЕ: запрещено после отправки).
- После голоса студент видит **агрегированную** статистику.
- При `isAnonymous`: преподаватель видит агрегаты; без привязки ответов к ФИО в UI студентов. Деталка для преподавателя: ⚠️ агрегаты по вариантам + число голосов; персональные ответы только если `isAnonymous=false`.

## Завершение

`now > endsAt` → голосование закрыто. Событие в персональную ленту преподавателя (модуль 6).

## QA фокус

Анонимность, SINGLE vs MULTIPLE, чужая группа, повторный голос, просмотр до голоса запрещён.
