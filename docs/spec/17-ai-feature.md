# 17 — Модуль 11: ИИ-функция в продукте

Любая полезная LLM-функция внутри приложения. Фиксируем **три** точки (минимум одна обязательна к демо; цель — все три):

| ID | Кто | Вход | Выход |
|----|-----|------|-------|
| AI1 | Teacher | Тезисы задания | Черновик description checkpoint |
| AI2 | Teacher | pollId | Текстовая сводка результатов опроса |
| AI3 | Student | context профиля (АР, просрочки) | 3–5 советов «как поднять рейтинг» |

## Требования

- Ключ LLM только в env (`LLM_API_KEY`), не в репозитории.
- Fallback: если LLM недоступен — сообщение «сервис временно недоступен», форма работает без ИИ.
- Не отправлять пароли/токены в промпт; для AI3 — агрегаты, не чужие ПДн.
- Промпты хранить в backend (шаблоны), версионировать.

## Тесты

- Unit: сборка промпта / парсинг ответа (mock HTTP).
- e2e: кнопка видна; при mock-ответе текст попадает в поле.
