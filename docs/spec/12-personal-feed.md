# 12 — Модуль 6: Персональная лента событий

Отличается от ленты наград (модуль 4): персональные события пользователя.

## События студента

| Код | Текст (шаблон) |
|-----|----------------|
| `CHECKPOINT_ASSIGNED` | Преподаватель назначил задачу «{title}» вашей группе |
| `DEADLINE_SOON` | До дедлайна «{title}» осталось менее {N} ч |
| `SUBMISSION_ACCEPTED` | Работа по «{title}» принята |
| `SUBMISSION_RETURNED` | Работа по «{title}» возвращена на доработку |
| `POINTS_AWARDED` | Вам начислено +{n} {БУА\|БОА} за «{title}» |
| `POLL_CREATED` | Новый опрос для вашей группы: «{title}» |
| `ACTIVITY_CREATED` | Новая активность: «{title}» |

## События преподавателя

| Код | Текст |
|-----|--------|
| `SUBMISSION_RECEIVED` | {student} сдал(а) работу по «{title}» |
| `POLL_ENDED` | Опрос «{title}» завершён |

## Формат UI

Блок: иконка + текст + относительное/абсолютное время. Сортировка: новые сверху. Пагинация cursor.

## Генерация

Писать событие в момент доменного действия (тот же use-case).  
`DEADLINE_SOON` — джоба раз в N минут, один раз на пару (user, checkpoint).
