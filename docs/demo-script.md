# Сценарий демонстрации UniRate (15 минут)

Перед демо:

```bash
docker compose down -v
docker compose up -d --build
```

Открыть http://localhost и http://localhost:8025 (Mailhog). Пароль всех демо-пользователей: `Demo123!`.

## 1. Студент: главный экран (1–2 мин)

Войти `student@demo.local`.

Показать:
- АР 1000→960 после тика worker (просроченная «Лабораторная работа 3», списание по 20 АР за тик).
- БУА/БОА раздельно, историю начислений, задания (активное + просроченное + принятое).
- Баннеры подтверждения email/группы (у seed-студента всё подтверждено).

## 2. Преподаватель: задание и ИИ (2–3 мин)

Войти `teacher@demo.local` → «Задачи» → «Создать задачу».
- Название «Курсовая работа, 1 этап».
- В блоке «ИИ-помощник» ввести тезисы и нажать «Сгенерировать описание» — описание заполняется, подпись «Демо-режим ИИ» (если ключ не задан).
- Дедлайн +2 дня, стоимость 100, группа ИВТ-21.
- Открыть ростер: студенты, статусы, списано.

## 3. Студент: сдача и уведомления (2–3 мин)

`student@demo.local` → «Мои задачи» → у новой задачи «Сдать работу» → ссылка `https://example.com/demo` → отправить.

`teacher@demo.local` → задача → выбрать студента → «Принять выбранные» → подтвердить.

Показать:
- У студента статус «Принято», списание остановлено.
- «Моя лента»: событие о принятии; «Уведомления»: in-app, отметить прочитанным.
- Mailhog: письмо-уведомление (email-канал).

## 4. Активность, бюджет и лента наград (2 мин)

`teacher@demo.local` → «Активности» → «Волонтёрство на Дне открытых дверей» → «Начислить баллы».
- Уровень 50 % → 50 БОА.
- Показать остаток бюджета группы и таблицу начислений.

`student@demo.local` → «Лента наград»: запись +50 БОА; «Профиль»: БОА и история.

## 5. Опрос и ИИ-сводка (1–2 мин)

`student@demo.local` → «Опросы» → «Формат итогового зачёта» → выбрать вариант → «Отправить голос».
- Показать агрегированные результаты и что повторный голос запрещён на backend.

`teacher@demo.local` → «Опросы» → этот опрос → «Сгенерировать сводку»: текст на основе агрегатов, без ФИО (опрос анонимный).

## 6. Админ-панель (2 мин)

`admin@demo.local` → «Администрирование».
- Справочники: факультеты/группы/кафедры (создание, удаление с защитой от связанных записей).
- «Импорт»: CSV `email,fullName,facultyName,groupName,passwordOptional` → отчёт created/skipped/errors → вход новым студентом.
- «Настройки»: изменить `arDeductAmount` и показать, что значение используется джобой (вернуть 20 после демо).
- «Семестры»: активация начисляет бонус с cap 1000 и запрещена повторно.

## 7. Аналитика и итоги (1–2 мин)

`teacher@demo.local` → «Аналитика»:
- динамика среднего/медианы АР (30 дней), рейтинги БУА/БОА;
- расход бюджета по месяцам, текущий лимит по группам.

Завершить архитектурой: слои backend, PostgreSQL + Flyway, JWT/RBAC, фоновый worker, тесты
(88 backend, 13 frontend, 8 E2E), CI и агентский журнал `docs/agent-log.md`.

## Запасные демо-аккаунты

- `lead@demo.local` — староста: «Заявки в группы», подтверждение `pending@demo.local`.
- `pending@demo.local` — студент без подтверждённой группы: задания не назначаются.
- `teacher2@demo.local` — проверка разграничения доступа (чужая группа → 403).
